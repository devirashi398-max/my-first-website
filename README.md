# 🎨 Artiva Studio

A creative and responsive portfolio website built using **HTML and CSS**.

Artiva Studio is a simple creative platform-style website designed to showcase artwork, creative services, and ideas through a clean and colorful interface.

## ✨ Features

* 📱 Responsive design
* 🎨 Creative hero section
* 🖌️ Features/services section
* 🖼️ Artwork gallery
* 💡 About section
* ⭐ Highlights section
* 💬 Contact section
* 🔗 Quick navigation links
* 📱 Social media icons
* ✨ CSS hover effects and animations
* 🌐 Deployed using GitHub Pages

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome
